# VP Bot — Discord-бот Военной Полиции

Заявки на вступление, запрос ролей, отпуска, запрос обучения, приветственная панель.
Работает **автономно**: данные в SQLite, настройки в `config.json`, никакого внешнего бэкенда не нужно.

## Запуск локально

```bash
npm install
cp .env.example .env      # впишите DISCORD_BOT_TOKEN
npm run dev               # или: npm run build && npm start
npm test
```

Нужен Node.js ≥ 20. В Developer Portal включите **Server Members Intent** (и **Message Content Intent**, если ставите `VP_MESSAGE_CONTENT_INTENT=true`).

## Настройки

| Что | Где |
|---|---|
| Токен бота, пути, прокси | переменные окружения (`.env.example`) |
| ID каналов и ролей, тексты панелей | [`config.json`](config.json) (не секретно, лежит в репозитории) |
| Данные (заявки, отпуска, ID сообщений панелей) | SQLite: `$DATA_DIR/bot.sqlite` (по умолчанию `./data`) |

Пустые значения в `config.json` = функция выключена (например, без `leaveRequestChannelId` нельзя подать отпуск).
После изменения `config.json` перезапустите бота.

Команды (только администраторы сервера и `adminDiscordUserIds`):
- `/setup-panels` — опубликовать/обновить приветственную панель и панель действий (также делается при каждом старте);
- `/setup-training` — опубликовать/обновить панель запроса обучения.

## Деплой на bothost.ru

1. Подключите этот репозиторий (GitHub), тип — **Docker** (используется `Dockerfile`).
2. Переменные окружения: `DISCORD_BOT_TOKEN`, при необходимости `VP_MESSAGE_CONTENT_INTENT`.
3. **Подключите постоянный диск (Volume) к `/app/data`.** На тарифе Starter файлы стираются при перезапуске — потеряются необработанные заявки, отпуска и ID сообщений панелей (панели будут опубликованы заново дубликатами). Нужен тариф с постоянным диском.
4. Минимум 256 МБ RAM достаточно.

## Интеграция с VDV (опционально)

«Розыск» (панель, алерты, досье) работает через API сайта VDV, потому что использует мониторинг игрового сервера VDV.

Интеграция включается, только если заданы **обе** переменные `BACKEND_PUBLIC_URL` и `VP_DISCORD_BOT_SECRET`. Без них бот не делает ни одного запроса в VDV. Код интеграции — [`src/vdv.ts`](src/vdv.ts) и пулеры `wanted-*`, `channel-*`.
Настройки розыска (каналы, роли) при включённой интеграции берутся из VDV, а не из `config.json`.

## Структура

- `src/api.ts` — логика заявок/отпусков/панелей (локально) и проксирование в VDV;
- `src/store.ts` — SQLite; `src/config.ts` — загрузка `config.json`;
- остальные файлы — обработчики Discord (панели, формы, модерация).
